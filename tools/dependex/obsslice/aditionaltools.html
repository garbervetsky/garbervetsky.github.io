Aditional tools

AutomataComposer: Generates the parallel composition of a  given network of timed automata. Supports KRONOS and OPENKRONOS  formats.

Usage:

  • java ta.AutomataComposer -e specificationFile

  • java ta.AutomataComposer -o OutputTA autName1...autNameN

Automata2Dot: Convert timed automata in KRONOS and OPENKRONOS formats to DOT format.

Usage:

  • java ta.Automata2Dot autName

AutomataTranslator: Convert timed automata in KRONOS to OPENKRONOS format and viceversa.

Usage:

  • java ta.AutomataTranslator aut1Name [autNam2...autNameN]

UPPAALTranslator: Convert network of timed automata in KRONOS and OPENKRONOS formats to an UPPAAL system (.xta).

Usage:

  • java uppaal.UPPAALTranslator outputDirectory specificationFile

ExpGenerator: Generates an .exp (OPENKRONOS specification file) for a network of timed automata.

Usage:

  • java openkronos.ExpGenerator  -e specificationFile
